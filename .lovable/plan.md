- Lovable’s docs do not expose a self-service setting in Lovable for Vercel firewall/bot protection on Lovable-hosted projects.

1. Add a `vercel.json` firewall rule  
   - Not possible. `vercel.json` can do redirects, rewrites, and headers, but not Vercel WAF / bot-protection allowlists.

2. Contact Lovable support to disable bot protection on this project  
   - Yes. This is the correct path if the block is truly happening at the hosting layer.

3. Exact support channel  
   - Use `https://lovable.dev/support`
   - If needed, email `support@lovable.dev`
   - Discord: `https://discord.gg/lovable-dev` for community visibility, but not as the primary escalation path.

Important limitation:
- This cannot be fixed from inside Lovable code if the 403 is generated by the hosting firewall before the request reaches your deployment.
- `robots.txt` does not override a firewall block.
- `vercel.json` cannot create WAF allowlist rules.
